# 🔌 PyForge VS Code Extension & Bridge

Интеграция PyForge прямо в **Visual Studio Code**. Позволяет автоматически отслеживать ошибки на лету, получать интеллектуальные подсказки от ИИ-наставника, применять 1-click автофиксы и решать практические задачи по любимым библиотекам.

---

## 🚀 Возможности

1. **Реалтайм ИИ-диагностика кода**:
   - Обнаружение опечаток в именах переменных и функций с предложением правильного варианта.
   - Определение отсутствующих импортов (`re`, `json`, `math`, `asyncio`, `pathlib` и др.) и их автоматическое добавление.
   - Проверка забытых `await` перед вызовами асинхронных функций.
   - Предупреждение об опасных изменяемых аргументах по умолчанию (`def foo(items=[])`).
   - Предупреждение об одиночном присваивании в условиях (`if x = 5:`).
   - Точные подчеркивания (волнистые линии) ошибок и предупреждений с подсказками.

2. **1-Click Quick Fixes (Лампочка / `Ctrl+.`)**:
   - Нажмите `Ctrl+.` (или `Cmd+.` на Mac) на любой подсвеченной ошибке для применения автоисправления.

3. **🎲 Генератор задач по библиотекам**:
   - Команда `PyForge: 🎲 Сгенерировать задачу по библиотеке` (`Ctrl+Shift+P` -> `PyForge: Random Task`).
   - Выберите любую библиотеку (`fastapi`, `re`, `kivy`, `openpyxl`, `sqlite3`, `pandas`, `pydantic` и др.) — и VS Code откроет готовый файл с условием, стартовым кодом и тестами!

4. **Быстрый переход в веб-студию PyForge**:
   - Кнопка в правом нижнем статус-баре: `$(sparkle) PyForge: Наставник`.

## ⚙️ Установка и запуск

### Способ 1: Использование моста PyForge из веб-интерфейса (Без установки расширения)
В веб-интерфейсе PyForge перейдите в раздел **«🔌 VS Code Bridge»** или введите путь к вашему рабочему файлу — PyForge будет автоматически читать его с диска и выдавать анализ в реальном времени!

### Способ 2: Запуск расширения в VS Code
1. Запустите сервер PyForge:
   ```bash
   python run.py
   ```
2. Откройте папку `vscode-extension` в VS Code:
   ```bash
   code vscode-extension
   ```
3. Нажмите клавишу **F5** (или вкладка *Run and Debug* -> *Launch Extension*). Откроется окно *Extension Development Host* с активным расширением PyForge!
4. Откройте любой `.py` файл и начните писать код — ошибки будут подсвечиваться автоматически!

## 🛠 Настройки (settings.json)

```json
{
  "pyforge.serverUrl": "http://127.0.0.1:8000",
  "pyforge.enableLiveDiagnostics": true,
  "pyforge.debounceMs": 350
}
```
