Экспорт и Восстановление базы данных

Сохраняйте всех пользователей, сессии, роли и титулы в один файл перед обновлением сайта.

1. Скачать резервную копию (Экспорт)

Скачивает файл pyforge_backup.json, содержащий всех зарегистрированных пользователей, их роли, пароли, звёзды, титулы, форум и идеи.

2. Восстановить базу из файла (Импорт)

Загрузите ранее скачанный файл бэкапа после обновления кода или передеплоя, чтобы моментально вернуть всех пользователей.

Облачная база данных Supabase PostgreSQL
Проверка подключения...

Когда настроены переменные SUPABASE_URL и SUPABASE_KEY, все регистрации, балансы, роли и посты сохраняются напрямую в ваше облако Supabase и никогда не сбрасываются.

SQL-скрипт для создания таблицы в Supabase SQL Editor (нажмите, чтобы открыть)

Скопируйте этот запрос и выполните его в Supabase ➔ SQL Editor ➔ Run:

CREATE TABLE IF NOT EXISTS pyforge_store (
  key TEXT PRIMARY KEY,
  value JSONB NOT NULL,
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);
ALTER TABLE pyforge_store ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow all access to pyforge_store" ON pyforge_store FOR ALL USING (true) WITH CHECK (true);
Все данные шифруются и проверяются сервером. Доступ к управлению базой есть только у Создателя Chevels.
