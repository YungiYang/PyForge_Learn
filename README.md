# ⚡ PyForge — Интерактивный комбайн и база знаний для создания приложений на Python

**PyForge** — это локальное интерактивное приложение, объединяющее исчерпывающую информацию, архитектурные шаблоны, конструктор готовых проектов под ключ, библиотеку сниппетов и песочницу для разработки любых приложений на Python (Desktop GUI, Web/API, Telegram-боты, CLI, Data/AI).

---

## 🚀 Как запустить

### Способ 1: Через скрипт запуска
```bash
cd C:\Users\user0\.gemini\antigravity\scratch\python_dev_hub
python run.py
```
*Скрипт автоматически запустит сервер и откроет интерфейс в вашем браузере по адресу `http://127.0.0.1:8000`.*

### Способ 2: Двойным кликом
- Просто дважды кликните по файлу **`start.bat`**.

## 📦 Разделы и возможности приложения

1. **🎮 Интерактивный Тренажер Практики & ИИ-Наставник (Practice & Live AI Mentor)**:
   - Каталог задач по уровням (*Junior*, *Middle*, *Senior*, *Architect*) с автоматической проверкой решений через скрытые и открытые тест-кейсы.
   - **Генератор задач с ИИ**: возможность создать уникальный квест на любую тему по запросу в 1 клик.
   - **🧠 Реалтайм ИИ-Наставник (Live Error Mentor)**: реагирует на ошибки прямо во время набора кода (задержка 350 мс), подсвечивает синтаксические ошибки, объясняет их причину на понятном русском языке и предлагает кнопку **«Применить исправление»**.
   - **⭐ Система Звёзд и Магазин Титулов (Title Shop)**: начисление звёзд за выполненные задания (`+15 ⭐`, `+35 ⭐`, `+75 ⭐`, `+150 ⭐`) с возможностью покупать и экипировать титулы (*«🐍 Начинающий Змеелов»*, *«📜 Мастер Списков»*, *«⚡ Адепт Асинхронности»*, *«🐛 Истребитель Багов»*, *«👑 Python Grandmaster»*).

2. **🤖 ИИ-Поисковик библиотек и источников (AI Library Scout)**:
   - Смысловой поиск библиотек под любую задачу (распознавание текста OCR, генерация PDF, парсинг с обходом Cloudflare, работа с Excel, локальные нейросети Ollama, обработка аудио).
   - 3 режима работы: **Live PyPI & Web Explorer** (живой поиск в реальном времени по сети и PyPI), **Smart AI Engine** (локальная база) и **External LLM / Ollama** (генерация ответов нейросетью).
   - Карточки решений с прямыми ссылками на PyPI, GitHub и официальную документацию, кнопкой копирования команды установки `pip install ...` и кнопкой «В песочницу».

3. **🚀 Конструктор проектов (Project Forge)**:
   - Выбор типа приложения:
     - **PySide6 Desktop Application** (Qt, фоновые QThread потоки, темный стиль, SQLite, сборка .EXE).
     - **FastAPI Clean Architecture Backend** (Pydantic v2, SQLAlchemy 2.0 async, SQLite, Swagger UI, Pytest).
     - **CustomTkinter Modern GUI** (легковесный современный десктоп с темной/светлой темой).
     - **Aiogram 3 Modern Telegram Bot** (роутеры, FSM-машина состояний, inline-кнопки).
     - **Typer + Rich CLI Application** (консольные утилиты с таблицами и прогресс-барами).
   - Интерактивный предпросмотр файлов и кода.
   - **Генерация в 1 клик** в любую выбранную папку на диске или скачивание готового ZIP-архива.

2. **🧩 Каталог фреймворков и библиотек**:
   - Сравнение, плюсы и минусы, команды установки и примеры быстрого старта для PySide6, CustomTkinter, Flet, FastAPI, Flask, Aiogram 3, Typer/Rich, Streamlit и Pygame.
   - Кнопка «Отправить в песочницу» для быстрого тестирования.

3. **🏛️ Архитектура и фундаментальные концепции**:
   - Современная структура проектов (`src/` layout, `pyproject.toml`).
   - Clean Architecture и Service-Repository паттерн.
   - Сравнение AsyncIO vs Threading vs Multiprocessing с таблицей применимости.
   - Паттерны проектирования на Python (Factory, Singleton, Observer/EventBus).
   - Строгая типизация Python 3.12+ (Type Hints, Generics, Pydantic v2).

4. **💾 Базы данных, ORM и Кэширование**:
   - SQLAlchemy 2.0 (современный Mapped Declarative Base, асинхронные сессии).
   - SQLite3 (оптимизация WAL-режима для многопоточности).
   - Миграции схемы БД с Alembic.
   - Кэширование и очереди задач с Redis.

5. **📦 Сборка в .EXE и распространение**:
   - **Интерактивный конструктор команд PyInstaller** (`--onefile`, `--windowed`, `--clean`, иконки, ресурсы `sys._MEIPASS`).
   - Компиляция в машинный C++ код через **Nuitka** для защиты от декомпиляции и ускорения.
   - Генератор сценария установщика Windows (**Inno Setup** `.iss` скрипт).
   - Двухэтапный (Multi-Stage) **Dockerfile** для веб-сервисов.

6. **⚡ Библиотека сниппетов и шпаргалок**:
   - Полнотекстовый поиск по тегам (`asyncio`, `pathlib`, `passwords`, `retry`, `decorators`, `matching`).
   - 100% проверенные куски кода с кнопками копирования и запуска.

7. **🧪 Интерактивная песочница (Playground)**:
   - Встроенный запуск фрагментов кода прямо в браузере с отображением времени исполнения в миллисекундах и выводом stdout/stderr.

8. **🔍 Глобальный быстрый поиск (`Ctrl + K`)**:
   - Моментальный поиск по всем темам, библиотекам, сниппетам и руководствам.
